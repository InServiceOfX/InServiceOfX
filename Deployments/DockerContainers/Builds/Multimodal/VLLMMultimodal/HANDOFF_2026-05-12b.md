### 4. CLIPDFTiledExtraction (commit `359592a`)

`PythonApplications/CLIPDFTiledExtraction/` — the key quality fix for dense P&IDs:
- `TileGenerator`: splits a PIL image into overlapping tiles with configurable
  grid (default 3×3, 15% overlap). Preserves original bbox per tile.
- `TagMerger`: parses one-tag-per-line VLM responses; normalises; deduplicates
  across tiles; records tile_coverage so multi-tile tags are more trusted.
  Optional cross-check against reference_tags from MinerU.
- `TiledRunner`: rasterise → tile → per-tile `Qwen3VLVLLM.generate` (greedy)
  → merge → write per-page JSON.
- 16 unit tests (TileGenerator + TagMerger), all green, no GPU needed.
- Run inside Docker: copy config examples, edit paths, then:
  ```bash
  python Executables/main_CLIPDFTiledExtraction.py --currentpath
  ```
  Expect ~9 tiles × 9 pages × ~8-10 s/tile ≈ 650-800 s total.

### 5. vector_store Ingest Binary (commit `c05e6a7`)

`RustLibraries/vector_store/src/bin/ingest.rs`:
- Reads a CLIPDFColQwenIndexer output directory (finds manifest.json in each
  subdir), upserts document + page records, stores safetensors bytes in
  `page_embedding_blobs`.
- `--dry-run` flag for safety.
- Build: `cargo build --bin ingest` inside `RustLibraries/vector_store/`
- Usage after `docker compose up`:
  ```bash
  VECTOR_STORE_DATABASE_URL="postgres://vector_store:vector_store@localhost:5433/vector_store_db" \
    cargo run --bin ingest -- \
    --index-dir /path/to/CLIPDFColQwenIndexer/<doc-name>-...
  ```

## Complete End-to-End Pipeline (as of today)

1. **MinerU extraction** → `CLIPDFExtraction` → `page_N.md` (JSON elements) +
   `page_N.png` in `/Workspace/Generated/CLIPDFExtraction/{doc}/`

2. **Qwen3VL full-page** → `CLIPDFQwen3VLChat` → `page_N.txt` in
   `/Workspace/Generated/CLIPDFQwen3VLChat/{doc}/`

3. **Tiled tag OCR** → `CLIPDFTiledExtraction` → `page_N.json` (merged_tags,
   tile_coverage, per-tile responses) in
   `/Workspace/Generated/CLIPDFTiledExtraction/{doc}/`

4. **ColQwen retrieval indexing** → `CLIPDFColQwenIndexer` → `page_N.safetensors`
   + `manifest.json` in `/Workspace/Generated/CLIPDFColQwenIndexer/{doc}/`
   (GPU end-to-end validation PENDING — run inside Docker with live config)

5. **ColQwen query** → `CLIPDFColQwenQuery` → JSON ranked pages (GPU pending)

6. **Postgres ingestion** → `cargo run --bin ingest` → `page_embedding_blobs`
   (requires Docker Compose Postgres running, ColQwen index written first)

7. **Viewer** → `PIDViewer` → http://localhost:8888 — browse all outputs,
   search extracted text, see tiled tags

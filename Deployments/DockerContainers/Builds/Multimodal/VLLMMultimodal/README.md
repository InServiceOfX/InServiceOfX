Base image: `nvcr.io/nvidia/pytorch:25.06-py3` — last CUDA 12.x release (CUDA 12.9.1, Python 3.12). Newer NVIDIA containers ship CUDA 13 and currently break vLLM / nunchaku.

## Component layout

The Dockerfile is auto-generated by `docker_builder` from the components below, in order:

1. `CommonComponents/Dockerfile.header` — generated-file marker
2. `CommonComponents/Dockerfile.base` — apt update, ccache, python-dotenv
3. `Dockerfile.system_deps` — poppler-utils + opencv libs (pdf2image deps)
4. `Dockerfile.pytorch_reinstall` — replaces NV's torch 2.8.0a0 alpha with stable 2.8.0 (vLLM rejects pre-release tags)
5. `Dockerfile.vllm` — pinned vLLM install + import sanity check
6. `Dockerfile.mineru` — mineru-vl-utils[vllm] + pdf2image

All version pins live in `build_configuration.yml` `build_args:`.
